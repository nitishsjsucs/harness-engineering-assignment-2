# A real run on `tasks/quickstart`

Eight experiments (the baseline plus seven), 2026-09-19, on an Apple M-series
laptop. `val_loss` went from **0.9605 to 0.0093**, a 99.0% reduction, in under a
minute of total compute.

![progress](progress.png)

## How this was produced -- honestly

These experiments were **not** proposed by a live language model. The seven
hypotheses were written by hand (by Claude, while building this harness) into
`scripts/quickstart_demo.json`, and then replayed through the real agent loop:

```bash
cp -r tasks/quickstart /tmp/example && cd /tmp/example
arh init . --tag sep19
arh baseline
arh loop --agent scripted --script .../scripts/quickstart_demo.json --max 8
```

`--agent scripted` swaps only the model. Everything else is the production
path: the same `TaskTools` with the same permission checks, the same
`run_experiment` tool, the same engine, guards, git operations and ledger. The
outcomes in the table below were measured, not scripted -- the script says what
to change, never what the result should be. That is exactly why experiment 6
(the reward-hacking attempt) is in here: it was written as an idea and the
harness rejected it.

Replacing `--agent scripted --script ...` with `--agent openrouter` runs the
identical loop against a live model; that is how it will be demonstrated on
camera. No API key is needed for anything committed here.

## What happened

| # | status | `val_loss` | description | why |
|---|---|---|---|---|
| 0 | keep | 0.9605 | baseline (unmodified code) | multinomial logistic regression |
| 1 | keep | 0.0511 | one hidden layer (16 tanh units) | a linear model cannot bend around a spiral |
| 2 | keep | 0.0428 | widen the hidden layer to 64 units | more capacity, fewer steps, still a win |
| 3 | **crash** | -- | relu units with a much larger learning rate (200) | diverged to NaN; `prepare.py` exited non-zero |
| 4 | keep | 0.0093 | add polar features (radius, sin/cos, two harmonics) | the spiral is simple in polar coordinates |
| 5 | discard | 0.0462 | much wider hidden layer (512 units) | 709 steps instead of 5223 in the same 3 s |
| 6 | **invalid** | -- | train on the validation split as well | the diff added `_split("val")`, a forbidden pattern |
| 7 | discard | 0.0095 | small weight decay (1e-4) | 0.0002 worse: inside the noise floor |

Experiment 6 is the point of the whole harness. The idea sounds reasonable in
prose ("more data should help"), it would have produced a better-looking
number, and it was rejected in 0.0 seconds -- before any compute was spent --
because the diff mentioned the private split helper. The edit was reverted
automatically and the loop carried on.

## What is in here

| path | what it is |
|---|---|
| `results.tsv` | the human-readable ledger, one row per experiment |
| `experiments.jsonl` | the same rows with everything else: reason, holdout score, extra metrics, log and diff paths |
| `runs/000N.log` | the complete stdout/stderr of each run |
| `runs/000N.confirm.log` | the holdout re-run for each keep |
| `runs/000N.diff` | exactly what was evaluated |
| `progress.png`, `report.md` | generated by `arh report` |
| `state.json` | the harness state at the end: branch, best commit, frozen hashes |
| `best-train.py` | the `train.py` the loop converged on |

Worth opening on camera: `runs/0006.diff` (the rejected reward hack) and
`runs/0003.log` (the NaN crash, and how the frozen evaluator refused to turn it
into a score).

The only edit made to these files after the run: the temporary directory the
run happened in was rewritten to `/tmp/example` in the logs, so the paths are
readable. Numbers, statuses, diffs and timings are untouched.
